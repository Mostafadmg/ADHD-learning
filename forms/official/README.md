# Original forms

Official copies of the pre-assessment forms used in Module 3, saved so they open in a browser tab instead of downloading.
Each file comes from its publisher (see the form library for the source link). Check each licence before redistributing.

| File | Source | Fillable |
|---|---|---|
| asrs-v1-1.pdf | ADDA copy of the WHO ASRS v1.1 Symptom Checklist (add.org) | No |
| wfirs-s.pdf | CADDRA (caddra.ca) | No |
| wsr-ii.pdf | CADDRA (caddra.ca) | No |
| snap-iv-26.pdf | CADDRA (caddra.ca) | No |
| snap-iv-26-fillable.pdf | Owner's copy of the SNAP-IV 26-item scale, branded by Clinical Partners. Not linked from the course (third-party branding); the course links the CADDRA copy | Yes |
| phq-9.pdf, gad-7.pdf | phqscreeners.com (no permission required to reproduce) | No |
| audit.pdf, audit-c.pdf | OHID, GOV.UK (Open Government Licence) | No |
| aq-10.pdf | Autism Research Centre, Cambridge (free for non-profit use) | No |
| pcl-5.pdf | US National Center for PTSD (public domain) | Yes |
| c-ssrs-screener.pdf | Columbia Lighthouse Project (free for clinical use) | No |

Not saved: WURS-25 (download blocked by a bot check), DAST-10 (author's permission needed; no official copy online), MDQ and MSI-BPD (no free official PDF), STOP-Bang and Epworth (restricted).

The course opens these through `forms/view.html?f=<file>` (PDF.js viewer: works where the browser cannot show PDFs; fillable forms can be typed into and downloaded filled).
